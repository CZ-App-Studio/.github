# CZ App Studio

We build **[Open Core HR](https://czappstudio.com/open-core-hr)**: HR and field workforce management software in one product.

- **HR:** employees, attendance, leave, expenses and approvals, with add-ons for payroll, performance, recruitment and onboarding.
- **Field workforce:** visits and live tracking with a mobile app for the team on the road, and add-ons for journey plans, sales orders, payment collections and targets.
- **25+ languages** included, on the web and in the app.
- **Two ways to run it:** on your own server with a self-hosted licence, or a private copy hosted and managed by us.
- **Built for AI agents:** AI-assisted setup is free, and the manual is agent-readable.

## Open source add-ons

These add-ons for Open Core HR are free and open source under the MIT licence. Open Core HR itself is commercial software supplied with source code to licence holders.

| Add-on | What it does |
|---|---|
| [AI writing assistant](https://github.com/CZ-App-Studio/open-core-hr-ai-writing) | Drafts, improves, shortens, formalises or translates text with the AI provider you connect |
| [Notes](https://github.com/CZ-App-Studio/open-core-hr-notes) | A private notebook for every employee, on the web and in the mobile app |
